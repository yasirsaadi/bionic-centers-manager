# 4.bn — المراجعةُ الشاملة، المرحلةُ الأولى: ثوابتُ البيانات على الإنتاج (٢٠٢٦-١٠-٠٢)

## لماذا الثوابت أوّلاً
سؤالُ المالك: «لو راجعنا التطبيق كلّه كخبير، هل نجد المزيد؟». فبدأنا بالأرخص والأدقّ: استعلامٌ واحد يقرأ **بيانات الإنتاج**
ويسأل أربعة عشر سؤالاً يجب أن يكون جوابُ كلٍّ منها صفراً. كلُّ صفٍّ يظهر خطأٌ **واقعٌ فعلاً**، لا احتمال. والمرحلةُ الثانية
(مراجعةُ الشيفرة بالمجالات) لم تُبدأ — تُطلَب صراحةً لكلفتها.

## النتيجة الأولى
أحد عشر ثابتاً نظيفاً تماماً (الدفعات · الزيارات · قيود الدفتر على قسم مريضٍ آخر · الفواتير · الأوامر · الأجهزة · المتابعات ·
الكلف السالبة · مريضٌ بلا قسم). والثلاثةُ الباقية — كلُّها في الكلفة — ١٥ ملفّاً، **كلُّها أثرٌ قديمٌ لعطبين أُصلحا قبلُ**،
لا خللٌ حيّ:

| المجموعة | العطب (مُصلَح في الشيفرة) | الملفّات | الإصلاح بقرار المالك |
|---|---|---|---|
| أ | «تعديل مريض» قبل ٢٠٢٦-٠٨-٣١ يحرّك الكليّة والدفتر ولا يحرّك بطاقة القسم (§ `cost-ledger-parity`) | 02183 · 02027 · 02010 · 02002 · 01983 · 01790 · 01591 · 01285 · 01009 · 01373 | كلفةُ القسم الوحيد = الكليّة |
| ب | الأثرُ نفسُه ثمّ قلمُ القسم أضاف الفرقَ مرّةً ثانية | 01554 | الكليّة ٨م ⟵ ٤م (سعرُ الطرف بقول المالك)؛ قيدٌ معاكس بتاريخ ٢٠٢٦-٠٩-٠٣، وقيدُ ٠٨-١٥ نُسب إلى القسم |
| ج | تخفيضٌ يدويّ ثمّ «تراجعٌ إداريّ» عكس سعرَ البيع كاملاً (`standingCostOf` — `test:reversal-standing-cost` أخضر) | 02581 | قيدٌ مصحِّح +١٣,٧٢٥,٠٠٠ بوقت القيد ٦٠٠٢ (٢٠٢٦-٠٩-١٤) |
| د | لا تعديلَ مسجّل — أرقامٌ قديمة | 01978 · 01803 · 01681 | بقول المالك: 01978 السعر ١,٠٥٠,٠٠٠ (قالب ٢,١٠٠,٠٠٠ بخصم ٥٠٪) فأُلغيت زيادة ٥٠٠ ألف بقيدٍ معاكس بتاريخها · 01803 جلسةٌ واحدة ٢٥ ألفاً (البطاقة ١٧٥ ⟵ ٢٥) · 01681 المتبقّي ١٥٠ ألفاً (البطاقة ⟵ الكليّة) |

**ومع أحمد جاسم (`WB-02209`، §4.bm) ستّة عشر ملفّاً صُحّحت.** كلُّ تصحيحٍ `DO` واحدٌ يتوقّف إن لم تطابق الأرقامُ ما رُئي،
جُرّب محلّياً على نسخةٍ مطابقة (والتكرارُ يُرفض)، وكتب سطرَ `audit_log` باسم «تصحيح بقرار المالك»، وتحقّق المالكُ بعده
(الكليّة = مجموعُ الأقسام = مجموعُ الدفتر في كلّ ملفّ). **والقيودُ المصحِّحة بمصدر `ledger_correction` وبتاريخ القيد الخاطئ
نفسِه** — فلا يتغيّر إيرادُ يومٍ آخر. ولا دفعةَ مُسّت.

## استعلامُ الثوابت — يُعاد تشغيلُه دورياً (قراءةٌ فقط)
```sql
WITH ap AS (SELECT id, patient_code, total_cost FROM patients WHERE deleted_at IS NULL),
cs AS (SELECT patient_id, SUM(cost)::bigint s FROM patient_cases GROUP BY 1),
ce AS (SELECT patient_id, SUM(amount)::bigint s FROM cost_entries GROUP BY 1),
paid AS (SELECT case_id, SUM(amount)::bigint s FROM payments WHERE case_id IS NOT NULL GROUP BY 1),
checks AS (
  SELECT '01 مجموع كلف الأقسام ≠ الكلفة الكلية' AS الفحص, ap.patient_code AS رمز
    FROM ap JOIN cs ON cs.patient_id = ap.id WHERE cs.s <> COALESCE(ap.total_cost,0)
  UNION ALL
  SELECT '02 مجموع دفتر الكلفة ≠ الكلفة الكلية', ap.patient_code
    FROM ap LEFT JOIN ce ON ce.patient_id = ap.id WHERE COALESCE(ce.s,0) <> COALESCE(ap.total_cost,0)
  UNION ALL
  SELECT '03 قسم جهاز (تلقائي) مدفوعه أكبر من كلفته', ap.patient_code
    FROM patient_cases c JOIN ap ON ap.id = c.patient_id JOIN paid ON paid.case_id = c.id
   WHERE c.case_type IN ('prosthetic','medical_support') AND c.cost_source = 'auto' AND paid.s > c.cost
  UNION ALL
  SELECT '04 دفعة بلا قسم', ap.patient_code
    FROM payments y JOIN ap ON ap.id = y.patient_id WHERE y.case_id IS NULL
  UNION ALL
  SELECT '05 دفعة على قسم مريضٍ آخر', ap.patient_code
    FROM payments y JOIN ap ON ap.id = y.patient_id JOIN patient_cases c ON c.id = y.case_id WHERE c.patient_id <> y.patient_id
  UNION ALL
  SELECT '06 زيارة على قسم مريضٍ آخر', ap.patient_code
    FROM visits v JOIN ap ON ap.id = v.patient_id JOIN patient_cases c ON c.id = v.case_id
   WHERE v.deleted_at IS NULL AND c.patient_id <> v.patient_id
  UNION ALL
  SELECT '07 قيد دفتر على قسم مريضٍ آخر', ap.patient_code
    FROM cost_entries e JOIN ap ON ap.id = e.patient_id JOIN patient_cases c ON c.id = e.case_id WHERE c.patient_id <> e.patient_id
  UNION ALL
  SELECT '08 فاتورة: المدفوع فيها ≠ دفعاتها', ap.patient_code
    FROM invoices i JOIN ap ON ap.id = i.patient_id
   WHERE COALESCE(i.status,'') <> 'cancelled'
     AND COALESCE(i.paid_amount,0) <> COALESCE((SELECT SUM(amount) FROM payments y WHERE y.invoice_id = i.id),0)
  UNION ALL
  SELECT '09 فاتورة: حالتها لا تطابق مدفوعها', ap.patient_code
    FROM invoices i JOIN ap ON ap.id = i.patient_id
   WHERE (i.status = 'paid' AND COALESCE(i.paid_amount,0) < i.total)
      OR (i.status = 'pending' AND COALESCE(i.paid_amount,0) > 0)
      OR COALESCE(i.paid_amount,0) > i.total
  UNION ALL
  SELECT '10 أمر تصنيع مفتوح وجهازه ملغى', ap.patient_code
    FROM prosthetic_work_orders w JOIN ap ON ap.id = w.patient_id JOIN patient_device_episodes e ON e.id = w.device_episode_id
   WHERE w.status NOT IN ('completed','cancelled') AND e.status = 'cancelled'
  UNION ALL
  SELECT '11 جهاز «قيد التصنيع» بلا أي أمر تصنيع', ap.patient_code
    FROM patient_device_episodes e JOIN ap ON ap.id = e.patient_id
   WHERE e.status = 'in_manufacturing'
     AND NOT EXISTS (SELECT 1 FROM prosthetic_work_orders w WHERE w.device_episode_id = e.id)
  UNION ALL
  SELECT '12 متابعة بيع مفتوحة وجهازها ملغى', ap.patient_code
    FROM post_exam_followups f JOIN ap ON ap.id = f.patient_id JOIN patient_device_episodes e ON e.id = f.device_episode_id
   WHERE f.status NOT IN ('closed_without_purchase','converted','closed_exam_cancelled','closed_admin_void','closed_request_cancelled','closed_decision_cancelled') AND e.status = 'cancelled'
  UNION ALL
  SELECT '13 كلفة سالبة (مريض أو قسم)', ap.patient_code
    FROM ap WHERE ap.total_cost < 0
       OR EXISTS (SELECT 1 FROM patient_cases c WHERE c.patient_id = ap.id AND c.cost < 0)
  UNION ALL
  SELECT '14 مريض فعّال بلا أي قسم', ap.patient_code
    FROM ap WHERE NOT EXISTS (SELECT 1 FROM patient_cases c WHERE c.patient_id = ap.id)
)
SELECT الفحص, COUNT(DISTINCT رمز) AS عدد_المرضى,
       array_to_string((array_agg(DISTINCT رمز ORDER BY رمز DESC))[1:15], '، ') AS أمثلة_حتى_15
FROM checks GROUP BY الفحص ORDER BY الفحص;
```

**تنبيهات القراءة**: الفحص ٠١ يُظهر أيضاً مريضاً بأكثر من قسمٍ عُدّلت كليّتُه من «تعديل مريض» (السلوكُ القائم لا يوزّع الفرق —
`caseCostSync: "ambiguous"`)، فليس كلُّ صفٍّ فيه عطباً. والفحص ٠٣ يخصّ الأقسام التلقائية وحدها.
